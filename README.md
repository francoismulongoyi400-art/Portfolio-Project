FRANCOIS MULONGOYI - PROFESSIONAL PORTFOLIO
============================================

ABOUT
-----
This project is a responsive personal portfolio website for Francois Mulongoyi,
a web developer focused on modern, user-friendly digital experiences.

The portfolio uses semantic HTML, CSS Grid, Flexbox, responsive breakpoints,
animated page elements, hover states, gradient styling, and local image assets.


PAGES
-----
index.html
    Homepage with the hero introduction, social links, CV download button,
    about preview, and service highlights.

about.html
    Detailed profile page with skills, progress bars, education information,
    statistics, and a portfolio call-to-action section.

services.html
    Services page with selected project cards and a technology skills grid.

contact.html
    Contact form for collecting a name, email address, phone number, and
    message. Submissions are prepared and sent through WhatsApp.

TECHNOLOGIES
------------
- HTML5 for page structure and semantic markup
- CSS3 for layout, styling, responsive behavior, animations, and transitions
- JavaScript for contact form handling
- Font Awesome for interface and technology icons
- WhatsApp API link for contact form submissions


DESIGN FEATURES
---------------
- Dark professional visual theme
- Teal and purple accent colors
- Responsive layouts for desktop, tablet, and mobile screens
- Sticky blurred navigation header
- Gradient headings and buttons
- Animated page entrance effects
- Floating and rotating image animations
- Hover effects for links, buttons, cards, images, and icons
- Responsive project gallery
- Skills progress bars
- Accessible labels, alt text, titles, and ARIA attributes


HOW TO RUN
----------
1. Open the project folder in Visual Studio Code.
2. Open index.html in a browser.
3. For automatic browser refresh during development, use the Live Server
   extension in Visual Studio Code and select "Open with Live Server".

This is a static website, so no backend server or package installation is
required for the main portfolio pages.


EXTERNAL RESOURCE
-----------------
The pages load Font Awesome from this CDN:
https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.3.0/css/all.min.css

An internet connection is required for the Font Awesome icons to display when
opening the pages locally. The rest of the website uses local files.


CONTACT FORM
------------
The contact form does not submit to a database. JavaScript validates the form,
creates a WhatsApp message containing the submitted details, and opens the
WhatsApp link.

Before publishing the website, review the WhatsApp phone number in the script
inside contact.html and replace it with the correct number if necessary.


CUSTOMIZATION
-------------
- Edit text and page content directly in the HTML files.
- Replace images in the images folder while keeping the referenced filenames,
  or update the image paths in the HTML.
- Change the main colors, backgrounds, borders, and transition values at the
  top of style.css inside the root section.
- Update social media URLs in index.html.
- Add the CV file referenced by the Download CV button before publishing.


BROWSER SUPPORT
---------------
The portfolio is designed for current versions of Chrome, Edge, Firefox, and
Safari. Modern CSS features such as CSS Grid, Flexbox, gradients, animations,
and backdrop-filter are used throughout the design.
